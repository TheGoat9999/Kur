# SOL DORADO vehicle visual assets

The current vehicle UI uses photographic prototype assets instead of CSS/SVG-drawn cars. These are temporary visual stand-ins for the fictional SOL DORADO vehicle models and can be replaced later with original generated or commissioned assets without changing the vehicle data model.
